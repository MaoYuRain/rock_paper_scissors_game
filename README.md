# 🪨 Rock–Paper–Scissors Game (C++)

A simple multi-player **Rock–Paper–Scissors** game implemented in **C++17**, featuring user registration, data persistence, and unit testing with **Catch2**.

---

## 🚀 Features
- Multi-user login system  
- Persistent storage (`/data/users.txt`, `/data/game_log.txt`)  
- Masked player input (hidden choices)  
- Menu-driven interface  
- Automated unit tests (Catch2)  

---

## 🛠️ Build & Run
```bash
git clone https://github.com/<your-username>/rock_paper_scissors.git
cd rock_paper_scissors
mkdir build && cd build
cmake ..
make
./RockPaperScissors
```

Run tests:
```bash
./tests/test_game
./tests/test_player
```
